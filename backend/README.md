# Backend

Bu klasör Node.js + Express tabanlı API uygulamasını barındıracak. Başlıca bileşenler:
- Kimlik doğrulama ve RBAC middleware katmanı
- Makine durum API’leri ve veri simülasyon entegrasyonu
- Raporlama, audit log ve AI analiz servisleri

> Not: Kurulum adımları backend projesi oluşturulduğunda buraya eklenecek.
